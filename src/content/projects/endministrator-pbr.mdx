## 角色演示与渲染实验

Endministrator PBR 演示包含角色入场、循环待机、材质切换和环绕观察。独立的 RenderLab 将展示流程拆成可重复操作的实验：固定角色和相机，切换着色方式，再单独改变主光方向或粗糙度，观察阴影分界、高光与轮廓的变化。

## 从模型数据到材质分区

静态角色和管理员动画角色有两条接入路径。Python 工具从 PMX 读取顶点、法线、UV、三角形索引与各材质段，整理贴图路径。C++ 读取导出的数据后，按材质槽调用 `CreateMeshSection_LinearColor()`，将网格和应使用的纹理绑定到同一分区。播放入场和待机的管理员则走骨骼网格路径，复用该角色的骨架、动画与入场 Niagara，再接入同一个观察展台。

描边也按材质分区生成。可描边的表面沿法线外扩，外扩量取决于源顶点倍率和材质边宽。眼部、口腔等在源模型中关闭描边的槽沿用原标记。出现不符合预期的黑边时，可以从发生问题的网格和材质槽查起。

## PBR 与风格着色对照

PBR 诊断视图把基础色和粗糙度接入 UE Default Lit。通用风格视图把世界法线、光向、视线、粗糙度和 UV 传给 HLSL 节点，结果接到 Unlit 材质的自发光输出。通用着色先算 `N·L`，再用 `smoothstep` 控制亮面和暗面的过渡宽度。镜面项使用法线与半程向量的点积，边缘光取决于法线与视线的夹角。调整光向时可以直接看到分段边界移动，调整粗糙度时则可以观察高光形状变化。

| 诊断视图 | 用它确认什么 |
| --- | --- |
| 基础色 | 亮斑、绣纹或面部色差是否已经存在于贴图 |
| 世界法线 | 将 `[-1, 1]` 的法线分量映射为颜色，观察相邻表面的方向变化 |
| `N·L` | 查看主光和表面朝向的关系，定位亮暗交界 |
| UV | 把 U、V 分别映射到红、绿通道，检查纹理坐标分布 |

## 固定姿势和机位，比较衣料与发束

通用着色可以看清光照规律，但衣袖、护具和头发共用同一套高光时，材质之间的差异不够明显。衣料实验沿用示例贴图的通道定义，R 控制金属度，A 对应平滑度并换算成粗糙度，B 对应 AO，G 用作镜面系数，再接入 Default Lit。头发将同一张细节图的 RG 和 BA 分别解算为漫反射法线和镜面法线，沿用示例工程的法线与发束函数，并调节两类响应的过渡和权重。

材质巡检把待机固定在 0.5 秒，锁定半身机位并隐藏粒子。在主光 35° 和侧光 −65° 两档下，各截取通用着色、示例材质和实验材质，总共六张。截图前等待着色器编译完成，两张实验材质图各有五个材质槽命中。项目记录中，主光下能分辨面罩纹理、袖口金属高光与内搭织纹，侧光下可以观察高光方向和暗部衣料细节。
